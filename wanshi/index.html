它做什么

用系统的媒体会话（MediaSession）与媒体通知两条链路，识别出「现在哪个 App 在播什么」， 整理成一份记录列表；要保存时，把在播放 App 里复制到的链接粘进来，由它下载到本地。

后台识别

前台服务每 1.5 秒读一次系统媒体会话，拿到 App 名、标题、播放状态与时长，常驻通知实时显示「正在播放：xxx」。

通知兜底

不暴露媒体会话的 App，只要有播放通知也能被识别，两条链路用「包名 + 标题」去重。

直链 / m3u8

mp4 等直链边下边写；m3u8 自动选最高码率，按顺序把分片拼成一个 .ts 文件。

三种给链接的方式

其它 App「分享 → 万视」、复制链接后回来自动带入、手动粘贴，都会唤起同一个保存弹窗。

存到公共目录

文件放到 手机存储/Download/万视/，下载完成通知点一下就能播放。

数据只在本机

识别记录最多存 60 条在本地，不联网上报任何内容，也不读取通知正文。

怎么编译

这是源码工程，APK 需要你自己用 Android Studio 构建一次（作者本机没有 Android 构建环境，不提供预编译包）。

1

装 Android Studio

Koala（2024.1）或更新版本，自带 JDK 17。工程用 Gradle 8.7 / AGP 8.5.2 / Kotlin 1.9.24。

2

打开 wanshi/ 目录

File → Open 选择本页所在目录，首次 Sync 会按 gradle-wrapper.properties 自动下载 Gradle 8.7。

3

连手机点 Run

开启 USB 调试后直接运行；要装到别的手机走 Build → Build APK(s)，产物在 app/build/outputs/apk/debug/。

4

首次启动授权

按提示打开「通知使用权」（系统设置里找到万视并允许），再点「开始识别」。通知权限用于显示识别状态与下载进度。

它做不到什么

先说清楚，免得白折腾

  1. 拿不到视频地址。系统只提供标题和播放状态，不提供 URL。抖音、B 站、腾讯视频的真实播放地址是私有接口 + 签名防盗链，任何第三方 App 都无法旁路获取——所以保存时要你把链接喂给它。
  2. 加密流下不了。遇到 AES-128 / SAMPLE-AES 的分片流会直接提示，不会假装在下载。
  3. 不碰 DRM。受 Widevine 等保护的内容一律无法保存。
  4. 不抓屏、不录屏、不读通知正文。只取媒体通知里的标题与副标题，数据只留在本机。
