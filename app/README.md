# app 文件夹 = 工资监视器本体

这个文件夹就是手机上那个 App 的全部内容。**改软件代码只需要动 `index.html`。**

| 文件 | 作用 | 要不要改 |
|---|---|---|
| `index.html` | **App 本体**：界面、金额计算、动画、样式全在这一个文件里 | 改代码就点这个 |
| `sw.js` | 离线缓存。让断网时也能打开 | 一般不碰；只有换了图标、或改了 sw.js 本身，才把里面的 `CACHE = 'salary-monitor-v15'` 版本号 +1 |
| `manifest.webmanifest` | 添加到主屏幕时的 App 名称、图标、启动方式 | 改 App 名字时用 |
| `icons/` | 桌面图标图片（192×192 和 512×512） | 换图标时用 |

## 改完怎么生效

改 `index.html` → Commit → 1~2 分钟后，所有人下次打开 App 自动就是新版。

**不用改版本号，也不用发版**，不需要点任何"检查更新"。
